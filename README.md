# Ses Odası for Windows

Electron tabanlı arkadaşlarla sesli sohbet uygulaması.

## Windows paketi

Windows sürümü GitHub Releases bölümünden indirilebilir. İlk kurulumda ZIP dosyasını açın ve `SesOdasi-win32-x64` klasöründeki `SesOdasi.exe` dosyasını çalıştırın.

## Derleme

Node.js LTS kurduktan sonra proje klasöründe `npm install`, ardından `node prep.js` ve `node build.js` komutlarını çalıştırın.

Uygulama güncellemeleri GitHub Releases üzerinden kontrol eder. Ayarlar kullanıcı profili altında saklanır.
